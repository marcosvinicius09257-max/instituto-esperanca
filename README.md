# Instituto Esperança

Site institucional fictício desenvolvido como projeto acadêmico durante minha formação em Análise e Desenvolvimento de Sistemas.

## 📌 Sobre o projeto

O Instituto Esperança é uma organização fictícia voltada para ações de educação, inclusão social e desenvolvimento de crianças e adolescentes em situação de vulnerabilidade social.

O projeto foi desenvolvido com o objetivo de aplicar na prática conhecimentos de desenvolvimento FrontEnd.

## 🚀 Funcionalidades

- Página inicial institucional
- Página de projetos sociais
- Formulário de cadastro
- Validação de campos
- Máscara para CPF
- Máscara para telefone
- Máscara para CEP
- Validação de CPF com JavaScript
- Confirmação de senha
- Layout responsivo

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
